# io.hierograph.web — no API documentation

This artifact is the Hierograph web UI, a single-page app written in TypeScript
and packaged under `META-INF/resources/ui`. The Hierograph server serves it at
`/ui/`.

It has no Java or Kotlin API, so there is no Javadoc. The sources are in the
`-sources` jar and at <https://github.com/code-kontor/hierograph> in
`hierograph-web/`.
